# PulseCore

PulseCore is a low-latency, high-performance processing suite featuring real-time processing and auto-scaling module capabilities.

The key benefits of using PulseCore include:

- PulseCore is a low-latency, high-performance
- processing suite featuring real-time processing
- and auto-scaling module capabilities

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/PulseCore.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

PulseCore is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
